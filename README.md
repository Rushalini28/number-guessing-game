# 🎯 Number Guessing Game

## 📌 About the Project
The Number Guessing Game is a simple Python project in which the computer randomly selects a number between 1 and 100. The player must guess the correct number using hints provided by the program.

The game tells the player whether their guess is too high or too low and displays the total number of attempts taken to find the correct number.

## ✨ Features
- Random number generation
- User-friendly terminal interface
- Hints for guesses that are too high or too low
- Attempt counter
- Input validation for invalid entries
- Range validation (1–100)

## 🛠️ Technologies Used
- Python 3
- Random module

## 📋 Requirements
- Python 3 installed on your computer
- Visual Studio Code or any Python-compatible editor

## 🚀 How to Run the Project

**Step 1:** Download or clone this repository.

**Step 2:** Open the project folder in Visual Studio Code.

**Step 3:** Open the terminal in the project folder.

**Step 4:** Run the following command:

```bash
python main.py
```

**Step 5:** Enter your guesses and follow the hints until you find the correct number.

## 🎮 How to Play
1. The computer selects a random number between 1 and 100.
2. Enter your guess in the terminal.
3. If your guess is too low, try a higher number.
4. If your guess is too high, try a lower number.
5. Continue until you guess the correct number.
6. View your total number of attempts.
